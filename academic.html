Research Experience

  • Jan 2025 – Feb 2026

    CON-NET: Platform-Agnostic Bot Detection Model

    TUBITAK & CHIST-ERA funded project · Supervisor: Prof. Onur Varol

    Project: Integrating CONtent and NETwork structure for detecting, understanding, and mitigating online misbehaviour

    Designed and implemented a platform-agnostic bot detection model as part of my graduation project. Implemented account and action-based VAE models and compared them with PCA for dimensionality reduction. Conducted feature engineering to ensure cross-platform compatibility and developed novel approaches (e.g. Learning to Place, SpringRank) to avoid distribution shifts across social media platforms.

  • July – Sep 2025

    Partial Observable Multi-Agent Path Finding with Constrained Communication

    Erasmus Internship, University of Luxembourg · Supervisors: Prof. Leon van der Torre & Dr. Pere Pardo Ventura

    Focus: Multi-Agent Systems, Epistemic Planning, Answer Set Programming

    Designed a framework to solve a novel variant of the Multi-Agent Path Finding (MAPF) problem featuring partial observability, decentralization, and anonymous task-sequential requirements with constrained communication. Modeled observation and communication using dynamic epistemic logic and employed Answer Set Programming for collaborative planning under uncertainty. Developed a simulation script to compare performance across different discovery methods and agent configurations.

  • Sep 2024 – Jan 2025

    Solving Matching Problems Using AI Methods

    PURE Project, Sabancı University · Supervisor: Prof. Esra Erdem

    Project Type: Program for Undergraduate Research (PURE)

    Designed a student-to-department assignment system using Gale-Shapley algorithm and Constraint Programming to balance student preferences, diversity goals, and department capacities.

    Project report: Stable Matching Report

  • Aug 2023 – Jan 2024

    Automatic Transcription of Ottoman Documents (AKIS)

    TUBITAK funded project · Supervisors: Prof. Berrin Yanıkoğlu & Dr. Esma Fatıma Bilgin Taşdemir

    Project: Automatic Transcription of Ottoman Documents with Deep Learning

    Contributed to improving the accuracy of automatic transcription system for historical Ottoman documents using deep learning. Enhanced image segmentation capabilities of existing R-CNN model and achieved significant improvement in model accuracy for document transcription, working with historical document datasets and OCR challenges.

  • July – Sep 2023

    A Digital Analysis of an Early Ottoman Chronicle

    PURE Project, Sabancı University · Supervisors: Dr. İnanç Arın & Dr. Mehmet Kuru

    Project Type: Digital Humanities Research

    Participated in a PURE (Program for Undergraduate Research) project supervised by Dr. İnanç Arın and Dr. Mehmet Kuru. Created geo-visualizations and interactive data analyses of Aşıkpaşazade's Chronicle, performed NLP analyses using BERT and BERTopic to explore sentiment and themes, and developed an LLM-based chatbot using GPT-3.5 to enable dynamic user interaction with the chronicle.

    Project report: How to Map Aşıkpaşazade's History
